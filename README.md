# EOG-Integrated Eyeglasses  

## 📌 Project Overview  
This project focuses on the development of eyeglasses integrated with Electrooculography (EOG) sensors to track eye movements by measuring electrical potential differences around the eyes. The technology is aimed at improving human-computer interaction and developing assistive devices for individuals with mobility or communication difficulties.  

## 🎯 Objectives  
- Develop a functional prototype of EOG-integrated eyeglasses.  
- Optimize electrode placement for accurate signal detection.  
- Implement robust signal processing techniques to acquire and process data in real-time.  
- Ensure user comfort and ease of use in the final design.  

## 📖 Literature Review  
The project explores:  
- **Electrode Placements**: Optimized for precise EOG signal capture.  
- **Signal Processing**: Median and low-pass filtering, notch filters for noise reduction.  
- **Fourier and Wavelet Transformations**: Used for distinguishing between noise and useful signals.  
- **Future Advancements**: Integration of wireless systems and machine learning models (CNNs/ANNs) to enhance classification accuracy and real-time processing.  

## 🚀 Current Status  
- ✅ **Design Finalization**: Completed CAD design of the eyeglasses frame.  
- ✅ **Coding**: Implemented pre-processing and processing algorithms for EOG signals.  
- ✅ **Data Collection**: Gathered data for blink detection and lateral eye movements using EXG PILL.  
- ✅ **Algorithm Development**: Blink detection algorithm implemented; timestamps stored in CSV.  
- ✅ **Biomedical Signal Processing**: Pre-processing, filtering, and Fourier analysis studied and applied.  

## ⚠️ Challenges Faced  
- **Noisy Signals**: Electrode movement and loss of contact caused distortions.  
- **Artifact Noise**: High-frequency EMG noise interfered with EOG signals.  
- **Electrode Stability**: Unstable signal detection due to placement issues.  
- **Solutions Explored**: Investigating spring mechanisms for stable electrode placement.
